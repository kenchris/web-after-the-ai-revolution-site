# The Web After the AI Revolution

The slides of a talk on WebMCP, small on-device models, MCP Apps and how an agent can be kept under control, as a web page.

Open the page, then use the arrow keys or space to move, `F` for full screen and `G` for an overview of all slides.
The demo videos play inside their slides.

The site is the `docs` folder of this repository, published with GitHub Pages.
