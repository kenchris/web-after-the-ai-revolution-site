WebGPU and WebNN

WebGPU

  • General compute on the GPU
  • Shipping in Chrome, Edge, Firefox and Safari
  • Runs today with Transformers.js and ONNX Runtime Web
  • Platform gaps remain (Linux, Android for some engines)

WebNN

  • A neural network API for CPU, GPU and NPU
  • W3C Candidate Recommendation draft
  • Editors from Intel and Microsoft
  • The route to the NPU from a web page
