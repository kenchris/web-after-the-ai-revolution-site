Act IV · MCP Apps

Tools inside a page, interface inside a chat

WebMCP

  • The page owns the tools
  • The agent calls them in the user's tab
  • Good for sites that already exist

MCP Apps

  • The server owns the tools and the interface
  • The host renders the interface in a sandbox
  • Good for tools that have no site of their own
WebMCP draft and MCP Apps specification.
