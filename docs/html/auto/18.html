Act II · Agents meet the web

Three hints, written by the page

readOnlyHint
Only reads. It changes nothing.
Default: false
untrustedContentHint
The output may contain text written by users or third parties.
Default: false
consequentialHint
Real-world and hard to undo: booking, paying, deleting.
Default: false
Written by the site itself, which has little reason to mislead its own users.
WebMCP draft: readOnlyHint, untrustedContentHint, consequentialHint. All default to false.
