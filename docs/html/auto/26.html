A hint that raises scrutiny

  • consequentialHint: true
  • untrustedContentHint: true
  • Safe to honor from anyone
  • It can only add friction

A hint that lowers scrutiny

  • readOnlyHint: true
  • consequentialHint: false (or just missing)
  • A claim by the page about itself
  • Never the only reason to skip a confirmation
