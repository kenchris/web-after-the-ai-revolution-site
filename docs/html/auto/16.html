Act II · Agents meet the web

A page registers a tool

document.modelContext.registerTool({
  name: "add_item",
  description: "Add an item to the list",
  inputSchema: {
    type: "object",
    properties: { title: { type: "string" } }
  },
  annotations: { readOnlyHint: false },
  async execute({ title }) {
    list.add(title);
    return { ok: true };
  }
});
A name, a description, a JSON schema and a function. The page keeps its own logic.
WebMCP draft, registerTool. The older name navigator.modelContext is deprecated.
