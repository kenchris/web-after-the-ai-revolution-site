Act III · On-device intelligence

Why run it locally

The economics

  • It is cheaper to use the device you already own
  • You are not renting servers for every request
  • The cost does not grow with every prompt

Physics and privacy

  • Private by design: personal data and secrets never leave the machine
  • No round trip, so lower latency
  • It works offline
Argument from "The AI PC and the modern era of the web", Intel, 2025.
