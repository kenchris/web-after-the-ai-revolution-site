The KV cache: what the model keeps for each token
next
The new token reads every stored K and V, then adds its own.
Without the cacheEvery new token would read the whole prompt again, from the first word.
With the cacheOne token of new work. The price is memory: it grows with every token in the context.
Keys and values (K and V) are what the attention layers compute for each token.
